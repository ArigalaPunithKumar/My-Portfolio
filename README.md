# A Punith Kumar React Portfolio

Responsive, animated React portfolio generated from `Punith_Kumar_Website_Resume.md`.

All portfolio text and collection data are loaded dynamically from
`public/portfolio-data.json`. Edit that single file to update the profile,
skills, projects, education, certifications, statistics, or contact links.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
